# 🚀 DevTask Dashboard

A responsive task management dashboard designed to help developers organize tasks, track progress, and manage priorities.

## ✨ Features

* 📊 Dashboard with task statistics and progress tracking
* ✅ Create, edit, complete, and delete tasks
* 🎯 Set task priorities and statuses
* 🔍 Search and filter tasks
* 📅 Track due dates and overdue tasks
* 💾 Save tasks using browser LocalStorage
* 📱 Responsive design for desktop and mobile

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Browser LocalStorage

## 🌐 Live Demo

**[Launch DevTask Dashboard](https://arhamkhancr608-rgb.github.io/devtask-dashboard/)**

## 🚀 Getting Started

1. Open the live demo above, or clone this repository.
2. Open `index.html` in your browser.
3. Start creating and managing your tasks.

## 📌 Project Notes

This is a frontend portfolio project. Tasks are stored locally in the browser and are not synchronized across devices.
